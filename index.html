Privacy Policy

Effective Date: October 14, 2026 • Flowvya Version 1.0.0

Our Zero-Trust Privacy Commitments

  • 100% Local Processing: Recording, screenshot capture, annotations, and document compilation (PDF/HTML) happen entirely inside your local Chrome browser.
  • Zero Telemetry & Tracking: We do not track your browsing history, run analytics scripts, or collect diagnostic telemetry.
  • Automatic Sensitive Field Masking: Password inputs and payment card fields are automatically detected and omitted from step capture.
  • Opt-In Zero-Knowledge Cloud Sharing: Web sharing links are encrypted on your device with AES-256-GCM. The decryption key lives exclusively in the URL fragment (#key=...) and never touches server logs.

1. Single Purpose & Scope

Flowvya is a specialized browser productivity extension designed to turn software workflows into step-by-step Standard Operating Procedures (SOPs), interactive guided tours, and training manuals.

Flowvya only activates when explicitly initiated by you clicking "Start Recording" or using keyboard shortcut Alt + Shift + S. It does not monitor, analyze, or intercept web browsing activity outside of an active recording session.

2. What Information Flowvya Collects (and Doesn't Collect)

During an active, user-initiated recording session, Flowvya captures:

  • Viewport Screenshots: High-resolution screenshots of the visible browser area at the exact moment you click or interact with an element.
  • Element Metadata: Button text, input labels, CSS classes, element bounding boxes, and viewport coordinates to automatically draft instructional step descriptions.
  • User-Authored Content: Custom step descriptions, annotations (arrows, badges, text notes), guide titles, and company branding you add in Flowvya Studio.
What Flowvya NEVER collects:
  • Your general browsing history, visited URLs outside recording, bookmarks, or cookies.
  • Passwords, API keys, or credit card inputs (automatically filtered out at source).
  • Personal identification data, IP addresses, or device identifiers.

3. Sensitive Input Masking & Privacy Redactions

Flowvya incorporates defensive privacy mechanisms directly into its content script and rendering engine:

  1. Input Redaction: Any input field with type="password", autocomplete="cc-number", or matching security tokens is masked with placeholders (••••••••) before capture.
  2. Pixel-Burning Redactions: When you draw black redaction boxes in Flowvya Studio, the underlying screenshot pixel data is permanently destroyed in-canvas before generating PDFs, HTML exports, or cloud uploads.

4. Local Storage & Data Retention

All guide data, screenshots, and drafts are saved directly to your local computer via Chrome's chrome.storage.local API.

  • User Control: You can delete any saved guide at any time from the Guide Library.
  • Complete Wipe: Uninstalling the Flowvya extension immediately and permanently removes all stored guides and screenshots from your browser.

5. Optional Zero-Knowledge Cloud Sharing

Flowvya includes an optional cloud sharing feature to generate web viewer links for colleagues or clients. If and only if you explicitly click "Generate Share Link":

  • Client-Side Encryption: The guide data and screenshots are encrypted directly in your browser using the native Web Crypto API with AES-256-GCM.
  • Zero-Knowledge Key Storage: The 256-bit encryption key is placed in the URL hash fragment (#key=...). Under internet standard RFC 3986, the URL hash is processed strictly on the client device and is never transmitted over HTTP to web servers or Firebase.
  • Storage Provider: The ciphertext is stored in Google Cloud Firestore (US region). Even if the backend database were inspected, it contains only encrypted blobs with zero access to the decryption keys.

6. Chrome Extension Permissions Justification

In accordance with Chrome Web Store Minimum Permissions Policies, Flowvya requests only the permissions strictly required for its core functionality:

Permission Type Technical Purpose
storage API Saves draft guides, settings, and Guide Library records locally in your browser.
unlimitedStorage API Allows saving multi-step workflows with high-DPI screenshots without hitting Chrome's 5MB quota.
tabs API Detects active tab switches during recording and opens Flowvya Studio upon finishing.
activeTab API Captures visible viewport screenshots when you click or interact with an element.
scripting API Injects capture listeners and live guided tour overlays onto existing web tabs.
<all_urls> Host Enables capturing workflows on any web application, CRM, or SaaS platform you record.

7. Third-Party Services & Analytics

Flowvya operates without third-party tracking or advertising SDKs.

  • Zero Analytics: No Google Analytics, Mixpanel, Segment, or tracking pixels are embedded.
  • Zero Third-Party Advertising: We never sell, rent, or monetize your data.
  • Zero External CDNs for Extension Core: All libraries (React, jsPDF, DOMPurify) are compiled directly into the extension package.
